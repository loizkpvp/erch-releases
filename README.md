# Erch — выпуски

Здесь лежат только готовые установщики Erch для Windows и файл `latest.json`, по которому программа узнаёт о новой версии. Кода здесь нет.

- Скачать: раздел **Releases** справа или сайт https://erch-seven.vercel.app
- Обновление: установленный Erch сам предложит новую версию — кнопка «Обновить».
- Каждый установщик подписан. Программа не поставит файл с чужой подписью.
